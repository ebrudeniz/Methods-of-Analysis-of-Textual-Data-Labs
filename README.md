# Methods of Analysis of Textual Data (MATD) - Labs

This repository contains my solutions for the MATD course at VSB-TUO.

## Assignments
* **Lab 1: BPE Tokenization** - Implementation of Word-level and Byte-level BPE.
* **Lab 2: N-gram Language Model** - Word completion, probabilities, and Laplace smoothing.
* **Lab 3: Pattern Matching** - Performance comparison of Brute Force, KMP, and BMH algorithms.
* **Lab 4: Automatic Word Correction and Fuzzy Search** - Implementation of Levenshtein distance, candidate generation, and frequency-based word correction.
* **Lab 5: Boolean Information Retrieval – Inverted Index and Queries** - Implementation of an inverted index with token normalization, complex Boolean query parsing (AND/OR/NOT), and an extended weighting model for ranked results.
